# Messaging baseline

**Based on public messaging.** These are lines from Stripe's public pages, as returned by web search on 13 November 2026. The pages could not be opened directly from here, so check the wording on the live page before quoting a line on camera. Customer figures are Stripe's own and are averages or single examples.

The messaging changes in every deal review report are written against this file.
